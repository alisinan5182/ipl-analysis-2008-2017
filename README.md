# IPL Cricket Data Analysis Dashboard (2008–2017)

## Project Overview

This project explores Indian Premier League (IPL) cricket data using Microsoft Excel. It presents cricket statistics through a dashboard and supporting analysis sheets to make match and player performance data easier to understand.

## Objectives

- Explore IPL match and delivery-level data.
- Analyze team performance and match outcomes.
- Examine toss-related statistics.
- Identify leading batsmen by runs scored.
- Summarize match and venue statistics through Excel analysis and visualizations.

## Tools Used

- Microsoft Excel
- Excel dashboard and data analysis features


## Key Analysis Areas

- Top batsmen by total runs.
- Team wins and match outcomes.
- Toss statistics.
- Venue-related statistics.
- IPL match and delivery data.

This project helped me practice organizing cricket data, analyzing performance statistics, and presenting information through an Excel dashboard.
